# J7 Launcher · pre-booking site

Static site for https://j7launcher.github.io (GitHub Pages). Bahasa Malaysia / English.

- `index.html`, `style.css`, `app.js`: the page. `SHEET_URL` in `app.js` is the bookings Sheet's web-app link.
- `apps-script/`: the Google Apps Script behind the bookings Sheet (see its README).
- `img/`: J7 Launcher screens and the WhatsApp link preview.

Independent project by a J7 owner; not affiliated with Jaecoo or Chery.
